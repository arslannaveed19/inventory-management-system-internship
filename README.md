# Inventory Management System

A console-based Inventory Management System built using Python.

## Features

- Add Product
- View Products
- Search Product by ID
- Search Product by Name
- Update Product
- Delete Product
- Check Stock
- Calculate Total Inventory Value
- Duplicate Product ID Validation
- Negative Price and Quantity Validation

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- Lists
- Dictionaries
- Functions
- Loops
- Conditional Statements

## How to Run

```bash
python main.py
